# SonettoHere Entertainment Tools

参考来源：`SonettoHere-main/tools/entertainment/TOOL.md`。

已迁移为 SuperAgent 原生工具：

- `answer_book`：答案之书，本地随机启发式回答。
- `tarot`：简化韦特塔罗，支持 `single` 与 `three`。

这些工具仅用于娱乐/启发，不应作为事实、医疗、法律、财务等高风险结论依据。
