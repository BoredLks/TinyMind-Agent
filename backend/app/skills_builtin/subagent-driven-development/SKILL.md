# 子代理驱动开发

把独立子任务派发给上下文隔离的子代理（用 dispatch_subagent 工具），既保护主上下文、又让子代理聚焦。

## 每个任务的流程

1. **实现**：`dispatch_subagent(role=implementer)`，给它**自包含**的任务描述（它看不到主对话，必须把所需上下文都写进去）。
2. **规范符合审查**：`dispatch_subagent(role=reviewer)`，核查是否漏做、多做、理解错。不信任实现者的报告，自己核实。
3. **代码质量审查**：规范通过后，再派一个 reviewer 看结构、命名、错误处理、测试。
4. 审查发现问题 → 让实现子代理修 → 再审，直到通过，再进入下一任务。

## 红线

- 子代理任务必须自包含；别让它去猜上下文。
- 顺序固定：实现 → 规范符合 → 代码质量，不能反。
- 审查有未决问题就不算通过，别"凑合"。
